# Data

Raw source datasets used by the training and exploratory workflows live in `data/raw/`.

## Files

- `raw/Grammy_IG_posts_v2.csv`
- `raw/Instagram_Analytics.csv`

The production Streamlit app does **not** read these CSV files at runtime. It uses the exported artifacts in `models/`.

## Public-repository note

Before publishing or redistributing these datasets, verify that their original licenses or terms permit public redistribution. The project files do not establish those rights.
